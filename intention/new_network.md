

首先，整个模型的神经网络分成三大部分：
1，输入部分
2，主体网络
3，输出部分

# 输入部分

## 输入数据
- 映射成动作 id 的我方手牌序列 （不定长）
- 映射成动作 id 的我方弃牌堆序列（不定长）
- 映射成动作 id 的我方抽牌堆序列（不定长）
- 本身就作为动作 id 的我方上回合动作（1个）
- 归一化后的我方血量
- 归一化后的我方能量数
- 映射成动作 id 的对方手牌序列 （不定长）
- 映射成动作 id 的对方弃牌堆序列（不定长）
- 映射成动作 id 的对方抽牌堆序列（不定长）
- 本身就作为动作 id 的对方上回合动作（1个）
- 归一化后的对方血量
- 归一化后的对方能量数
- 当前轮内回合数（-1表示第一回合,0表示第二回合,1表示第三回合）
- 映射为状态 id 的我方状态序列（不定长）
- 我方状态的持续回合数序列（不定长，和我方状态id一一对应）
- 映射为状态 id 的对方状态序列（不定长）
- 对方状态的持续回合数序列（不定长，和对方状态id一一对应）

## 数据处理
1，将双方所有的手牌、弃牌堆、抽牌堆中的动作 id 都经过一个可学习的 embedding 层（称为e1，词汇表数为50），得到 emb1 向量（32维）

2，将 本身就作为动作 id 的我方上回合动作（1个）和 本身就作为动作 id 的对方上回合动作（1个）通过 e1，得到嵌入向量

3，将映射为 id 的双方状态序列分别输入第二个可学习的 embedding 层（称为e2），得到双方状态嵌入向量序列 S1, S2（8维）


# 主体部分

## 主体部分的输入数据
- 我方手牌嵌入向量序列 （不定长）
- 我方弃牌堆嵌入向量序列（不定长）
- 我方抽牌堆嵌入向量序列（不定长）
- 我方上回合动作嵌入向量（1个）
- 归一化后的我方血量
- 归一化后的我方能量数
- 对方手牌嵌入向量序列 （不定长）
- 对方弃牌堆嵌入向量序列（不定长）
- 对方抽牌堆嵌入向量序列（不定长）
- 对方上回合动作嵌入向量（1个）
- 归一化后的对方血量
- 归一化后的对方能量数
- 当前轮内回合数（-1表示第一回合,0表示第二回合,1表示第三回合）
- 我方状态嵌入向量序列（不定长）
- 我方状态的持续回合数序列（不定长，和我方状态id一一对应）
- 对方状态嵌入向量序列（不定长）
- 对方状态的持续回合数序列（不定长，和对方状态id一一对应）

## 主体网络的处理过程

1，计算带序数编码的嵌入向量

1.1 对我方手牌、弃牌堆、抽牌堆中的嵌入向量挨个计算序数，即该动作在我方 [手牌+弃牌堆+抽牌堆] 这个总序列中是第几次出现。举个例子：
举个例子：
我方手牌：1,3,9
我方弃牌堆：2,4,9
我方抽牌堆：2,9
加上序数后：
我方手牌：（1,序数为1）(3,序数为1) (9,序数为1)
我方弃牌堆：（2,序数为1）(4,序数为1) (9,序数为2)
我方抽牌堆：（2,序数为2）(9,序数为3)

然后，把序数通过第三个可学习的 embedding 层（称为e3），得到序数编码（2维）。
序数编码的作用类似于gpt里面的位置编码。不同的是，gpt里的位置编码是把位置下标映射为 embedding 向量，而我这里是把该动作第几次出现映射为 embedding 向量。

然后，把序数编码拼接在 emb1 后面，拼接后做层归一化，得到带序数编码的嵌入向量 emb2 (34维)。

2，计算卡组优势特征向量

2.1， 把我方手牌、弃牌堆、抽牌堆的带序数编码的嵌入向量并排组成一组，称为我方卡组向量序列
2.2， 使用一个可学习的查询向量 Q1，对我方卡组向量序列做 标准缩放点积注意力（Scaled Dot-Product Attention），再经过层归一化，得到一个综合向量 Z1，这个向量为我方卡组特征向量
2.3， 使用同一个 Q1，对对方卡组做同样的处理，得到 Z2，即对方卡组特征向量
2.4，使用第二个可学习的查询向量 Q2，对 Z1、Z2 做标准缩放点积注意力（Scaled Dot-Product Attention），再经过层归一化，得到 Z3，即我方卡组优势特征向量（34维）

3，计算双方状态特征向量

3.1, 将我方状态持续回合数序列输入一个全连接层 1 -> 32 -> 16，取 0-7下标作为向量 w, 8-15下标作为向量 b
3.2, 对我方状态嵌入向量做变换 S1' = S1 * w + b
3.2，对对方状态做同样的处理，得到 S2'
3.3, 对我方所有的 S1' 求和池化得到 SS1，对对方求和池化得到 SS2。SS1 和 SS2 即为双方状态特征向量 

4，计算 gru 单元

4.1，将 双方上回合动作嵌入向量、双方状态特征向量 拼接作为 gru 单元的 input 输入一个一层的 gru 单元，得到 h_out (32维)

5，计算手牌优势特征向量

5.1，对 h_out 做一个线性变换 + 层归一化，得到 34 维的 h_out'。将 h_out' 和我方手牌带序数编码的嵌入向量组成一个新序列 hh1
5.2，对 hh1 做标准 self-attention + 层归一化，得到我方手牌内部特征向量序列 HZ1
5.3，将 h_out' 和对方手牌带序数编码的嵌入向量组成一个新序列 hh2
5.4，对 hh2 做标准 self-attention + 层归一化 （和5.2共享权重），得到对方手牌内部特征向量序列 HZ2
5.5， 做我方手牌对对方手牌的 cross attention。即：
使用第二套权重，在 HZ1 上面的每个向量上计算出 q1, k1, v1。在 HZ2 上面的每个向量上计算出 q2, k2, v2。
然后，
for each_vector in HZ1:
    用 each_vector 的q1 对 HZ2 的每个向量做 cross attention，然后层归一化，得到 each_vecotor_z
    each_vector = each_vector_z
对新的 HZ1 做层归一化。
做完这一步，HZ1 的每个向量，既包含了自身手牌间的 combo 关系，也包含了对对手卡牌的克制关系
5.6，使用第三个可学习的查询向量 Q3，对 HZ1 做标准缩放点积注意力（Scaled Dot-Product Attention）+ 层归一化，得到手牌优势特征向量 HAZ (34维)

6，计算输出特征向量
把归一化后的双方血量、双方能量数、当前轮内回合数、双方上一回合动作的 embedding 向量、手牌优势特征向量、卡组优势特征向量、h_out 统统拼接到一起，经过一个三层的 fc-linear + relu，压缩成一个 32 维的输出特征向量 out

# 输出部分（policy网络）

## 输出部分的输入数据
把 out 作为输出部分的输入

## 输出部分的处理过程
将 out 通过一个和 e1 共享权重的 fc-linear 层，得到一个输出维度为 50 的向量。

# 输出部分（value网络）

## 输出部分的输入数据
把 out 作为输出部分的输入

## 输出部分的处理过程
将 out 通过一个 fc-linear 层，得到一个标量

# 权重文件
policy 网络和 value 网络是两个互相独立的网络，权重文件也完全分开。
但每个网络内部的 e1、e2 放在同一个权重文件里，其余部分放在另一个权重文件里。
所以一代 ai 一共会有四个权重文件。分别是：
policy_e1_e2.pth
policy.pth
value_e1_e2.pth
value.pth
