本文件放置完整的卡牌定义。

# 术语定义
- 状态。特指玩家玩家状态。
- 造成 x 点伤害。目标的生命值减少 x 点，且触发所有伤害 hook
- 造成 x 点生命流失。目标的生命值减少 x 点，且触发所有生命流失 hook，不触发伤害 hook

# 玩家状态定义
- 防御
    - 效果：由具体卡牌决定
- 联防
    - 效果：由具体卡牌决定
- 脆弱
    - 效果：拥有脆弱状态的玩家无法获得防御和联防效果

# 基础卡包
- 攻击
    - 效果1：如果对方没有防御状态，则对对方造成x点伤害。x等于我方连续出攻击的回合数（包括本回合，但最高不超过3）
        - 优先级：10
    - 构建时消耗能量：1
- 防御
    - 效果1：如果己方没有防御状态，则赋予己方防御状态，该状态持续到本回合结束。否则防御状态持续回合数+1
        - 优先级：11
    - 效果2: 如果己方上回合有防御状态，则赋予己方联防状态，持续到本回合结束。
        - 优先级：12
    - 构建时消耗能量：1
- 重击
    - 效果1：除非对方有联防状态，否则对对方造成1点伤害，并赋予对方持续2回合的脆弱状态
        - 优先级：10
    - 消耗能量：2
- 防守反击
    - 效果1：如果己方没有防御状态，则赋予己方防御状态，该状态持续到本回合结束，否则防御状态持续回合数+1
        - 优先级：11
    - 效果2：如果对方出的牌是攻击或重击，对对方造成1点伤害
        - 优先级：10
    - 消耗能量：2
- 聚能
    - 效果1：己方能量+1
        - 优先级：10
    - 消耗能量：1
- 构建
    - 效果1：选择任意一张可以构建的卡牌进行构建，可以构建的判断方式为： can_build = 卡牌消耗能量数 <= 己方能量条中的能量数。选中后，消耗选中卡牌的能量消耗量，然后把一张选中卡牌直接放入弃牌堆。如果己方能量为0，无法打出构建牌
        - 优先级：10
    - 消耗能量：1
- 攻守兼备
    - 效果1：如果己方没有防御状态，则赋予己方防御状态，该状态持续到本回合结束，否则防御状态持续回合数+1:
        - 优先级：11
    - 效果2：如果对方没有防御状态，对对方造成1点伤害
        - 优先级：10
    - 消耗能量：2
