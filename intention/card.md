本文件放置完整的卡牌定义。

# 术语定义
- 状态。特指玩家玩家状态。
- 造成 x 点伤害。目标的生命值减少 x 点，且触发所有伤害 hook
- 造成 x 点生命流失。目标的生命值减少 x 点，不触发伤害 hook

# 玩家状态定义
- 防御
    - 效果：由具体卡牌决定
- 联防
    - 效果：由具体卡牌决定
- 脆弱
    - 效果：拥有脆弱状态的玩家无法获得防御和联防效果

# 基础卡包
- 连续击
    - 效果1：如果对方没有防御状态，则对对方造成x点伤害。x等于我方连续出连续击的回合数（包括本回合，但最高不超过3）
        - 优先级：10
    - 构建时消耗能量：1
    - 标签：攻
    - 描述：快速地连续出击。如果对方没有防御状态，则对对方造成x点伤害。x等于我方连续出连续击的回合数（包括本回合，但最高不超过3）
- 格挡
    - 效果1：防御状态持续回合数+1
        - 优先级：11
    - 效果2: 如果己方上回合有防御状态或联防状态，则己方联防状态持续回合数+1
        - 优先级：12
    - 构建时消耗能量：1
    - 标签：防
    - 描述：专注防守。获得一回合防御状态。连续防御则可获得联防状态
- 破防重击
    - 效果1：除非对方有联防状态，否则对对方造成1点伤害，对方脆弱状态回合数 +2，且立刻移除对方的防御状态
        - 优先级：10
    - 消耗能量：2
    - 标签：攻
    - 描述：以巨大蛮力破开对方的防守
- 防守反击
    - 效果1：己方防御状态回合数+1
        - 优先级：11
    - 效果2：如果对方出的牌带“攻”标签且没有防御状态，对对方造成1点伤害
        - 优先级：10
    - 效果3: 如果己方上回合有防御状态或联防状态，则己方联防状态持续回合数+1
        - 优先级：12
    - 消耗能量：2
    - 标签：防
    - 描述：在防守的同时进行反击，连续防御则可获得联防状态
- 聚能
    - 效果1：己方能量+1。如果本轮及上轮有打出过聚能，则额外增加一点能量
        - 优先级：10
    - 消耗能量：1
    - 描述：获得1格能量。如果本轮及上轮有打出过聚能，则额外增加一点能量
- 构建
    - 效果1：选择任意一张可以构建的卡牌进行构建，可以构建的判断方式为： can_build = 卡牌消耗能量数 <= 己方能量条中的能量数。选中后，消耗选中卡牌的能量消耗量，然后把一张选中卡牌直接放入弃牌堆。如果己方能量为0，无法打出构建牌
        - 优先级：10
    - 消耗能量：1
    - 描述：构建一张新的卡牌
- 攻守兼备
    - 效果1：己方防御状态持续回合数+1。如果本轮及上轮有打出过”防“卡，则额外增加一回合防御状态
        - 优先级：11
    - 效果2：如果对方没有防御状态，对对方造成1点伤害
        - 优先级：10
    - 消耗能量：2
    - 标签：攻，防
    - 描述：一边进攻一边防守，只有高手才能做到如此平衡。如果本轮及上轮有打出过”防“卡，则额外增加一回合防御状态。但本卡无法获得联防状态
