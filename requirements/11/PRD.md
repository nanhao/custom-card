# PRD: 游戏机制大改版 — 能量、牌堆、轮次与状态系统 (intention #11)

## 1. 概述

对现有2人对战卡牌游戏进行全面机制升级：
- **能量条系统**：玩家获得能量后可用"构建"卡制造新卡牌扩充牌组
- **牌堆系统**：抽牌堆与弃牌堆分离，每轮洗牌重抽
- **轮次机制**：每轮5回合，回合结束后进入新轮，循环至游戏结束
- **状态系统**：防御状态、联防状态等可叠加状态
- **优先级结算**：卡牌效果按优先级高低依次结算，同优先级同时结算
- **卡牌扩充**：从4种卡牌（攻击/防御/重击/反击）扩展至7种（+聚能/构建/攻守兼备）
- **血量上调**：初始血量从3改为20
- **轮末扣血**：每轮结束时双方各扣1血，防止无限循环

原有PVP热座模式和人机对战模式均适用新机制，无需额外模式。

---

## 2. 游戏流程

### 2.1 开局
- 双方血量各20点，能量各0点
- 抽牌堆初始7张（2攻击/1防御/1重击/1反击/1聚能/1构建），弃牌堆空，手牌空
- 游戏直接进入第1轮

### 2.2 轮次流程
1. **轮开始**：双方手牌（若有）全部放入弃牌堆 → 弃牌堆全部移入抽牌堆 → 洗牌 → 各抽7张
2. **轮内回合进行**：进行5个回合，每回合双方各出一张牌，面朝下同时翻牌结算
3. **轮结束**：若游戏未结束（无人HP归零），双方各扣1血 → 进入下一轮

### 2.3 游戏结束
- 任一方HP降至0时游戏结束
- 双方同时降至0则为平局
- 不再有回合数上限

## 3. 卡牌定义

| 卡牌 | 效果 | 优先级 | 构建消耗 |
|------|------|--------|----------|
| **攻击** | 对方无防御状态时，造成X点伤害（X=连续出攻击回合数，含本回合，最高3） | 10 | 1能量 |
| **防御** | 效果a: 无防御状态→获得防御状态(持续到本回合结束)；已有→防御状态回合数+1 | 11 | 1能量 |
|  | 效果b: 已有防御状态时→获得联防状态(持续到本回合结束) | 11 |  |
| **重击** | 对方无联防状态时，造成1点伤害 | 10 | 1能量 |
| **反击** | 效果a: 与防御效果a相同 | 11 | 2能量 |
|  | 效果b: 对方出的牌是攻击或重击时，造成1点伤害 | 11 |  |
| **聚能** | 能量+1（能量上限5，达上限后无效） | 10 | 1能量 |
| **构建** | 选择一张可构建的卡牌（目标卡构建消耗≤当前能量），消耗对应能量，将该卡放入弃牌堆 | 10 | 1能量 |
| **攻守兼备** | 效果a: 与防御效果a相同（优先级11） | 11 | 2能量 |
|  | 效果b: 对方无防御状态时，造成1点伤害（优先级10） | 10 |  |

### 3.1 构建规则
- 打出"构建"卡后，从7种卡牌中选择一种进行构建
- 构建条件：目标卡牌的构建消耗 ≤ 当前能量
- **约束**：能量为0时无法打出构建卡（手牌中有构建卡也无法使用）
- 构建消耗能量后，目标卡直接放入己方弃牌堆
- 已构建的卡牌在下轮开始时随洗牌进入抽牌堆，有机会被抽出

### 3.2 状态规则
- **防御状态**：使攻击和攻守兼备效果b的伤害无效
- **联防状态**：使重击的伤害也无效
- 防御状态和联防状态均持续到**当前回合结束**（此后若没有新获得，则自动消失）
- 状态在回合间**不自动保留**——必须每回合重新通过防御/反击/攻守兼备获得
- 所有状态在新一轮开始时**清除**（每轮第一回合双方均无状态，需重新打出防御类卡牌获得）

## 4. UI 设计

### 4.1 主菜单（不变）
保持现有双按钮布局：👥 Player vs Player / 🤖 Player vs AI

### 4.2 游戏界面 — 新增/变更元素

**状态栏**：
- 血量：显示数值（如 "18/20 HP"），不再使用爱心图标
- 能量条：可视化能量槽（0-5格）
- 状态指示：显示当前生效的状态标签（防御/联防）
- 牌堆信息：显示抽牌堆剩余张数、弃牌堆张数

**手牌区**：
- 从4种卡牌扩展至7种，新增图标和颜色
- 卡牌显示数量 ×N

**回合信息**：
- 显示"第X轮 · 第Y/5回合"

**构建界面**：
- 打出构建卡时弹出选择面板，列出7种可构建卡牌
- 标注每张牌的构建能量消耗
- 能量不足的卡牌置灰不可选

**结算面板**（不变但适配新卡牌）：
- 展示双方打出的卡牌、伤害、HP变化

**对局记录**（不变但适配新卡牌）

## 5. 验收标准

### 5.1 能量系统
| # | 验收标准 |
|---|----------|
| AC-E1 | 游戏开始时双方能量均为0 |
| AC-E2 | 打出"聚能"卡后，己方能量+1 |
| AC-E3 | 能量达到5后，继续打出"聚能"不增加能量 |
| AC-E4 | UI中能量条正确展示当前能量值（0-5） |

### 5.2 牌堆系统
| # | 验收标准 |
|---|----------|
| AC-D1 | 初始抽牌堆7张，弃牌堆空，手牌空 |
| AC-D2 | 每轮回合开始时，手牌归入弃牌堆，弃牌堆洗入抽牌堆，抽7张 |
| AC-D3 | 玩家能查看自己的抽牌堆和弃牌堆内容 |
| AC-D4 | 玩家不能查看对方的抽牌堆和弃牌堆内容 |
| AC-D5 | 每回合结束后，打出的牌进入各自弃牌堆 |

### 5.3 轮次机制
| # | 验收标准 |
|---|----------|
| AC-R1 | 游戏开始后直接进入第1轮第1回合 |
| AC-R2 | 每轮进行恰好5回合 |
| AC-R3 | 每轮结束时双方各扣1血 |
| AC-R4 | HP、连续攻击计数、状态在新一轮开始时保留 |
| AC-R5 | 游戏仅在HP归零时结束，无轮数上限 |
| AC-R6 | PVE模式下AI可跨轮正常运作 |

### 5.4 状态系统
| # | 验收标准 |
|---|----------|
| AC-S1 | 防御状态使攻击和攻守兼备效果b的伤害无效 |
| AC-S2 | 联防状态使重击的伤害也无效 |
| AC-S3 | 同回合内已有防御状态时再出防御，防御状态延长并获得联防 |
| AC-S4 | 状态在本回合结束时失效（除非本回合又获得了新状态） |

### 5.5 优先级结算
| # | 验收标准 |
|---|----------|
| AC-P1 | 优先级11的效果先于优先级10的效果结算 |
| AC-P2 | 同优先级效果同时结算（汇总伤害后统一扣血） |
| AC-P3 | 攻守兼备的两个效果按各自优先级独立结算 |

### 5.6 卡牌效果
| # | 验收标准 |
|---|----------|
| AC-C1 | 攻击连续计数最高3，对方无防御时造成计数等量伤害 |
| AC-C2 | 重击仅在对方无联防时造成1伤害 |
| AC-C3 | 反击的效果a和效果b均正常工作 |
| AC-C4 | 构建选择目标卡并消耗能量后成功放入弃牌堆 |
| AC-C5 | 攻守兼备效果a（防御）和效果b（攻击）均正常工作 |
| AC-C6 | 所有卡牌只能选择手牌中持有的卡 |
